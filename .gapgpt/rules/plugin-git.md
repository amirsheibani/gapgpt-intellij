# Git commits & PRs

- Never add a `Co-Authored-By:` trailer for an AI assistant, or any AI attribution line ("Generated with …"), to commit messages or PR descriptions, whether the assistant commits or only suggests the message text.
- Match the repo's commit style (check `git log --oneline`): conventional prefixes like `feat: …` / `fix: …` with a short imperative summary.
- Commit only when the user asks.
